# 背景

日常や業務の気づき、あとで見返したい記事や投稿を、LINE のキープメモに残している。新しいメモアプリを選ぶのが面倒なことと、専用アプリは能動的に開きにいかないと見ないのに対し、LINE は1日に何度も開くので、書いた内容が自然に目に入る。こうした隙間時間のメモはインタースティシャルジャーナリングと呼ばれる。

YouTube、X、Qiita などで良いと思ったリソースも、同じキープメモにすぐ残すことが多い。

## 課題

- **種類が混ざり、縦に積まれる。** 技術記事、画像、気づき、TODO が同じ場所にあり、後から区別して見づらい。チャット画面の性質上、量が増えるとスクロールも大変になる。
- **Notion は過剰で、目に入る頻度も低い。** 本計画は Notion で作っており、何気ない一言メモを書くには重く、ワークスペースも汚したくない。LINE の方が日常的に目に入る。
- **保存先が媒体ごとに散らばる。** 良い記事や投稿は各プラットフォームにも保存しているが、何がどこにあるかを気にするのが面倒。
- **既存ツールは前提が合わない。** 似た用途のツールはあるが、LINE を入口に Web でもモバイルでも使えるわけではなく、自分用にカスタマイズもできない。
